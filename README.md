## 發布到 GitHub Pages
1. 把這個資料夾裡的所有檔案（含 `assets` 資料夾和 `.nojekyll`）上傳到一個 GitHub 專案的根目錄。
2. 專案的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
3. 約 1–2 分鐘後，網址會是 `https://<帳號名稱>.github.io/<專案名稱>/`。
